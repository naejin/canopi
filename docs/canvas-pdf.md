# Export a Canvas PDF

Open a Design and choose **File → Export to PDF**. Desktop opens a PDF save dialog; Web Edition requests a PDF download. The PDF is for sharing and printing. Keep the `.canopi` file to edit your Design later.

Choose A4 or US Letter, orientation, and the Design Layers to print. Initially, the export uses the visible printable layers. These choices never change visibility or other content in your Design. Maps and the Timeline, Budget, and Consortium tabs are excluded.

The first page gives an overview. For detailed field sheets, select existing Zones or use **Draw a print area** on the overview. Print Areas are temporary rectangles; they do not create Zones. Choose a common detail scale from 1:20, 1:50, 1:100, 1:200, 1:500, and 1:1000, with individual overrides where useful. Large areas split into overlapping sheets at that scale. The overview and neighboring-page references identify the final page numbers.

Each canvas sheet has a narrow plant legend using the current language's common name when available, otherwise the full botanical name. Plant symbols and colours stay as authored. Annotations and pinned plant names remain visible regardless of canvas zoom. If several species share an appearance, the preview warns you; you can return to the Design to edit it or export as shown.

If a legend does not fit, enable **Allow legend continuation pages** or adjust the print setup. Continuation pages identify their source sheet and preserve complete names and appearances. Export stays unavailable while a legend overflows.

Close the preview to edit the Design, then reopen it to keep the current session's print choices. A renamed or removed selected Zone needs review. Opening a different Design discards the old print setup. Generating or saving a PDF never marks the editable Design as saved.

Print at **100% / actual size**. Disable the printer dialog's fit-to-page scaling. The calibration bar measures 50 mm on every canvas page; its distance label states the corresponding ground distance. Overview scales are approximate; detail scales are fixed. The current physical defaults are still awaiting the recorded [paper and field review](canvas-pdf-validation.md).
