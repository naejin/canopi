# Export a Canvas PDF

Open a Design and choose **File → Export to PDF**. Desktop opens a PDF save dialog; Web Edition requests a PDF download. The PDF is for sharing and printing. Keep the `.canopi` file to edit your Design later.

Choose A4 or US Letter and the Design Layers to print. Initially, the export uses the visible printable layers. These choices never change visibility or other content in your Design. Maps and the Timeline, Budget, and Consortium tabs are excluded.

The first page gives an overview. For detailed field sheets, select existing Zones or use **Draw a print area** on the overview. Each selection opens a new page fitted to the entire area, with the best orientation chosen automatically. Exact squares use portrait. Print Areas are temporary rectangles; they do not create Zones. Large areas fit on one canvas page, and the overview identifies each detail page's coverage and final page number.

Under **This page**, set **Canvas zoom (%)** to adjust the printed drawing. **100%** fits the whole area; lower values show more surroundings, and higher values enlarge around the centre and may crop the area. **Reset fit** returns to 100%. Choose an orientation for each page independently; changing orientation refits the area at the current zoom. Legend continuation pages also have individual orientation controls. Use the page arrows or an area's view button to return to its settings. **Preview zoom** only changes the page's on-screen size.

Each canvas sheet has a narrow plant legend using the current language's common name when available, otherwise the full botanical name. Plant symbols and colours stay as authored. Annotations and pinned plant names remain visible regardless of canvas zoom. If several species share an appearance, the preview warns you; you can return to the Design to edit it or export as shown.

If a legend does not fit, enable **Allow legend continuation pages** or adjust the print setup. Continuation pages identify their source sheet and preserve complete names and appearances. Export stays unavailable while a legend overflows.

Close the preview to edit the Design, then reopen it to keep the current session's print choices. A renamed or removed selected Zone needs review. Opening a different Design discards the old print setup. Generating or saving a PDF never marks the editable Design as saved.

Print at **100% / actual size**. Disable the printer dialog's fit-to-page scaling. The calibration bar measures 50 mm on every canvas page; its distance label states the corresponding ground distance. Each page has its own fitted physical scale; the displayed scale ratio is approximate. The canvas zoom setting is separate from the printer's 100% setting. The current physical defaults are still awaiting the recorded [paper and field review](canvas-pdf-validation.md).
