# Built-In Plant Symbols

Plant Symbols are a fixed built-in set stored as IDs in the Design file, not uploaded artwork or Species Catalog data. The approved botanical family replaces the old geometric/habit set as an intentional breaking presentation change: canopy, conifer, palm, shrub, herb, grass, bamboo, fern, climber, groundcover, rosette and cactus, plus an Abstract group of `round` (neutral fallback), square, triangle and cross. Abstract shapes complement the botanical vocabulary for designer-defined meanings. The square, triangle and cross IDs return with solid, softened geometry; retired botanical IDs and the old wave have no aliases or retained artwork. Unrecognized strings use the normal fallback. The JSON field structure is unchanged.

The family favors distinct opaque silhouettes at small sizes over fine botanical illustration. Compact outlines omit small cuts; detailed outlines add those cuts where space permits. Native contour data supplies the picker, Canvas2D, Pixi, stamp placement and PDF. Fully enclosed holes are counter-wound; open gaps are part of the outline because native cutout APIs cannot reliably subtract holes touching an edge.

**Consequences**:
Plant Symbols remain user-chosen, scene-owned presentation, independent of catalog taxonomy and physical geometry. The circular Visual Footprint, nearest-spacing cap, hit testing, selection rings, stacking and zoom-to-fit behavior remain unchanged. Distant marks become position dots. Renderers consume native line/cubic primitives without runtime SVG parsing, image textures or a new dependency. See [canvas guidance](../agent/canvas-runtime.md) and [PDF guidance](../agent/canvas-pdf.md) for display thresholds.
