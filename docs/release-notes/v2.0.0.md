# Canopi 2.0.0 Release Notes

## One Spatial Workspace

- Work with botanical drawing and geographic data in the same Canvas. MapLibre
  owns navigation and presentation while geographic rendering is available;
  Canvas2D remains the editing fallback.
- Keep every Design anchored through a required Spatial Frame. New Designs start
  with a deterministic provisional placement that makes no real-site claim.
- Preview, confirm, cancel, reset, undo, and redo site placement without changing
  local-metre Plant, Zone, Annotation, or Measurement Guide geometry.
- Keep basemap, LiDAR, geographic references, grid, Design objects, and
  interaction overlays in one defined back-to-front order.

## Intentional Design Format Break

- Canopi 2.0.0 reads and writes `.canopi` format version 6. Older, missing,
  invalid, and future format versions are rejected before replacing the active
  Design.
- Version 6 requires one provisional or confirmed Spatial Frame. Canopi does not
  silently fabricate placement for an older Design and does not include a legacy
  conversion layer.
- Rejected files and existing app data remain untouched.

## Preserved Design And LiDAR Behavior

- Retain local-metre botanical editing, Species presentation, Layers, locks,
  groups, history, Canvas PDF, Desktop save, Web download, and Canvas2D fallback.
- Retain the existing LiDAR library, imports, display, coverage navigation, and
  scientific analysis boundaries. LiDAR stays above the basemap and below
  geographic references, grid, Design objects, and interaction overlays.
- Keep camera movement and display changes independent from stored geometry and
  numeric LiDAR analysis results.

## Capacity And Performance Limits

- The representative 2,201-Plant Design passed the required rendering, editing,
  persistence, ordering, fallback, and lifecycle checks.
- Temporary dense and dispersed 10,000-Plant Designs passed functional data,
  interaction, fallback, and cleanup checks. Smooth 10,000-Plant editing is not
  guaranteed.
- Reference-hardware frame-time and input-latency targets were not reached. The
  measured misses and test limits are recorded in the
  [production workspace capacity evidence](../v2-production-workspace-capacity.md).
