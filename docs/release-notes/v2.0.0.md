# Canopi 2.0.0 Release Notes

## The map is the canvas

- Every Design is drawn directly on the map. Basemap, satellite imagery, LiDAR,
  contours and hillshade are the background of the design surface; there is no
  separate Location step or placement anchor.
- Every design object is geolocated: plants, zones, annotations and measurement
  guides are stored in WGS84 longitude/latitude. Panning, zooming and place
  search move only the view, never your objects.
- A new Design opens where you last worked, or at a world view with a
  "Search your site" prompt.

## Map layers

- Basemap: OpenFreeMap vector styles (Liberty, Positron, Bright, Dark) with
  labels in your language.
- Satellite: Google imagery by default, with no key needed; add your own Google
  Maps API key in the Satellite row to use the official Map Tiles API. Sentinel-2
  cloudless imagery from EOX (about 10 m per pixel) is the alternative. Turning
  Satellite on hides the Basemap. Your Google key stays on this device and never
  enters Designs, exports or logs.
- Contours and hillshade stay available as map layers. Map layers are app
  settings shared by every Design.

## Place search

- The pin button under the inspection lens (or Ctrl+F) searches a place name or
  typed coordinates. Names are looked up through OpenStreetMap Nominatim on
  Enter only; coordinates are read locally without a request.

## GeoJSON

- Export a Design's objects as a GeoJSON FeatureCollection, and import GeoJSON
  points, polygons and lines as plants, annotations, zones and measurement
  guides in one undoable step. Available on Desktop and Web.

## Intentional break with 1.x

- Canopi 2.0 reads and writes `.canopi` format version 7 only. Designs saved by
  Canopi 1.x (format 6 and older) are refused with a clear message; there is no
  converter.
- LiDAR libraries created by earlier builds are deleted on first start and must
  be imported again.
- Older user data that Canopi 2.0 cannot read is set aside rather than migrated.
  Web Edition storage from 1.x is ignored.
- The Canvas2D fallback renderer is gone. If WebGL2 or the map cannot start, the
  canvas shows "Map unavailable" and the open Design stays loaded and saveable.

## Known limits

- Performance tuning for very dense Designs is scheduled after 2.0.
- Canvas PDF does not include map backgrounds in 2.0.
