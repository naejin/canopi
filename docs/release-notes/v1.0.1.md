# Canopi Desktop 1.0.1 Release Notes

Release date: 2026-08-21

## Fixes And Reliability

- Fixed pinned plant names drifting away from their plants after zooming or panning on high-DPI and fractional-scale displays. The same correction keeps Canvas2D selection labels, annotations, measurements, and stack badges aligned on Windows, macOS, and Linux.
- Made application and canvas labels update immediately when the interface language changes.
- Hardened document persistence, document switching, and Design Template imports so older asynchronous work cannot replace a newer user choice or save a stale Design snapshot.
- Improved desktop and Web Edition Species Search consistency for localized names, Unicode matching, short queries, result ordering, paging, and cancellation.
- Reduced UI stalls and concurrency races by bounding native background work and making user-data database initialization atomic.
