# Canopi 2.0.1

A small update to Canopi 2.0 for Desktop and the Web Edition.

## Fixed

- Measurement guides rotate: select a guide, alone or with plants, zones and notes, and turn it with the rotation handle or Rotate… (Ctrl Alt R). Both ends turn about the selection's centre. A single plant still has no rotation handle, since plant symbols stay upright.

## Changed

- Canopi Desktop's Plant catalog now comes from the same plant data as the Web Edition, the export of 26 September 2026.
- The Web Edition at web.projectcanopi.com is updated with every release, starting with this one.

## Before you upgrade

Installing 2.0.1 over 2.0.0 keeps your Designs, Drafts, Data library and settings.

The installers are not signed yet. On macOS (12 or later), open Canopi once, then go to System Settings › Privacy & Security › Open Anyway; if macOS says the app is damaged, run `xattr -dr com.apple.quarantine /Applications/Canopi.app` in Terminal. On Windows, if SmartScreen appears, click More info › Run anyway.

The known limits of [Canopi 2.0.0](https://github.com/opencanopi/canopi/releases/tag/v2.0.0) still apply.

## Source code

Canopi is AGPL-3.0-or-later free software; its installers include the GeoLibre tool, which contains the AGPL-3.0-or-later `wbspatialstats` tools. The complete source of this release is Canopi at tag `v2.0.1` plus the `geolibre-rust` and `whitebox-wasm` revisions in `desktop/THIRD_PARTY_NOTICES.md`, linked from the release page.
