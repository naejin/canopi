# Canopi 1.1.1 Release Notes

## Clearer Field Prints

- Identify plants through their symbols and colours when those appearances are unique. Ambiguous plants use simple enclosures or existing Species Codes, with fewer labels and no connecting plant lines.
- Keep complete, compact plant keys beside or below the detailed drawing when space permits. Additional key pages appear only when needed, and detail numbers stay consecutive.
- Read zone dimensions and stored measurement guides on the overview and detailed sheets. Transparent zone interiors keep overlapping zones, plants and annotations visible and reduce printing ink.
- Print contextual annotations where they fit. Crowded notes use the selected detail's key; notes outside selected details no longer create unexpected extra pages.
- Preserve every edge of irregular four-sided zones when deriving dimensions.

## Reliability And Maintenance

- Update frontend dependencies to resolve reported security issues, including MapLibre attribution sanitization.
- Make Design Notebook row moves atomic and keep document-replacement retries tied to the current session.
- Improve ownership and cleanup of panel-reordering gestures, Species Catalog refreshes and retained canvas presentation.
- Remove the superseded PDF bracket and routing implementation, expand regression coverage and keep Desktop and Web Edition print layouts aligned.
- Bind release promotion to the exact verified candidate commit and prevent accidental replacement of published releases.
