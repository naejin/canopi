# Canopi 1.2.0 Release Notes

## Planning In The Workspace

- Plan seasonal work in a full Calendar panel with month navigation, dated tasks and focused keyboard editing.
- Review quantities and costs in the Budget panel, including currency-aware totals and a downloadable CSV in the Web Edition.
- Build and inspect plant guilds in the Consortium panel while keeping the canvas visible.
- Use Calendar, Budget, Consortium, Design Notebook, Species Catalog, Favorites, Layers and Species Key in one resizable Desktop side dock instead of switching to separate planning canvases.

## Desktop And Web Together

- Use the same workspace, panel navigation and shared commands in the Desktop and Web editions. Calendar, Budget and Consortium are now available in the browser edition.
- Keep browser work in local Drafts and explicit Downloads while Desktop retains native Open and Save behavior.
- Preserve complete Design data when replacing or reopening documents, including fields an edition does not currently edit.
- Keep Species Catalog and Favorites presentation consistent across editions while retaining their separate storage adapters.

## Reliability And Development

- Improve canvas-host cleanup and retry behavior across document replacement, remounting and development hot reloads.
- Add deterministic Desktop, Web and memory-only gallery commands with isolated ports and combined production-build checks.
- Verify browser bundles for native imports and hosting asset limits, and package versioned `/app/` and root-domain Web Edition artifacts with manifest checksums.
