### BG3/BG2 — one paged generation read path and complete display means

Adapt the existing catalogue/resolver, not a second raster backend. A generation-scoped read owner supplies bounded pages of **published, spatially intersecting** chunk records in stable `(chunk_y, chunk_x)` order; use a fixed maximum page size (256 records) with a keyset cursor and SQL filtering before loading records. The owner captures immutable generation/role identity and retains the existing deletion/cancellation lease. Release catalogue locks before file/GDAL work. Use exact signed integer overlap tests; never visit absent coordinates. Window reads fetch only intersecting references. Whole-generation jobs may stream all occupied pages, but must not accumulate them into a complete `Vec`, map or manifest. Audit production callers of `persisted_chunks`/`generation_chunk_assets`, including slope/review/publication, so the helper is not merely bypassed in one tile function. Small dense test oracles may remain test-only.

Use the existing power-of-two rule without tying its level to the 1024-cell read cap. If a target footprint needs level 11 or above, evaluate that larger rectangle by streaming intersecting occupied chunks: add stored sum/count for wholly enclosed chunks; read intersecting portions of boundary chunks in bounded windows. Invalid/absent cells contribute neither sum nor count. Keep a scalar sum/count and bounded page/window buffers. The mean is total sum / total valid count, **not the unweighted average of chunk means**. A zero total count is invalid. Unsupported/non-finite coordinates and checked-arithmetic overflow return unavailable explicitly; they must not silently select level 10 or become empty coverage.

Keep valid-normalized bilinear interpolation of reduced cells as required by design §7. Native cell centres are at half-integer coordinates relative to a corner geotransform; for reduction side `s`, reduced centres are `(k + 0.5) * s`. Apply this convention consistently to source and reduced-grid interpolation and neighbouring XYZ tiles. Do not merely paint the containing chunk's mean. Reuse means under the existing shared memory budget, with cancellation between pages/reads; never require a full overview pyramid. No pixel/footprint/SQL-row collection grows with empty envelope area. A safeguard may return explicit unavailable for a genuine resource failure, not silently shorten the footprint and return an incorrect colour.

Decisive tests before claiming repair:

- Displacement 2048 selects level 11. A 2048² aligned reduced cell with four fully valid 1024² chunks of constants 0, 10, 20, 30 has mean **15**. Another cell with only 3 valid samples of value 2 and 1 of value 10 has mean **4**, not 6. Entirely absent/invalid cells stay transparent; missing/corrupt referenced files remain errors.
- Put valid coverage in an intersecting chunk other than the one containing the sample's coordinate. Its contribution must survive zoom-out; placing the same samples adjacent or across chunk boundaries must not change the result. Assert numeric means independently, then test the actual tile renderer and expected ramp/alpha, including reduced-cell centre and between-centre interpolation, negative coordinates and adjacent XYZ edges. Replace the test that currently blesses the level-10 clamp, explaining the contract correction.
- Seed more than two pages of occupied records with known sums plus distant irrelevant records. Assert all necessary pages contribute exactly once, each returned page is at most 256, and the small-window path never materializes unrelated records. Cancellation between pages terminates cleanly; subsequent healthy read passes. Use actual catalogue/resolver calls, not a mock of the paged behavior. Query-plan/index choice and private method names are delegated.
