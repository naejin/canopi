# Canvas v2 inventory: what exists today and what happens to it

Status: agreed (2026-09-29); input to docs/plans/canvas-v2-plan.md

This is the current-state inventory behind `docs/plans/canvas-v2-plan.md` and `docs/plans/canvas-v2-spec.md`. It covers every place that assumes a north-up or axis-aligned screen, and every copy of the world-to-screen transform. It also lists where input, tools, camera and rendering are entangled, every raw input listener, camera writer and focus or keyboard handler on the canvas path, every document statement of north-up or the old controls, and the stored data that touches bearing. Each row has a stable ID, so the plan, the beads and the reviewers can cite it (for example `INV-CAM-09`).

## How to read it

- **Revision.** Code citations are `file:line` in this worktree at `0f05d927`, re-checked on 2026-09-29 against the research reports (drifted lines are corrected; section 12 lists the corrections). The 0A research of 2026-09-30 re-checked the camera rows at `8210fc74`: `runtime.ts` and `renderers/scene-types.ts`, which the seams commit edited, are cited there; every other file is unchanged since `0f05d927`. Document citations are at `HEAD` (`git show HEAD:<file>`), because the planning change is already rewriting some of those files.
- **Paths.** Code paths are relative to `desktop/web/src/` unless they start with `common-types/`, `desktop/`, `docs/` or `.interface-design/`.
- **Fate.** `keep` (true under rotation and the new controls), `change` (the file stays, the behaviour or wiring changes) or `delete` (removed, with its replacement named).
- **Phase.** `seams`, `0A`, `0D1`, `0B`, `0C`, `0D2`, `F`, `1`, `2`, `3`, `R`, as defined in `docs/plans/canvas-v2-plan.md`; `plan` means the planning change that adds this inventory; `—` means no work. A row whose phase is `seams` alone (INV-TEST-13) is cleared by the seams commit, which records it on canopi-f47t.5; a row naming `seams` beside later phases stays open until the last of them.
- **Decisions.** ADR 0015 (rotating map and canvas controls), 0016 (one view transform), 0017 (input pipeline and gestures), 0018 (narrow tool interface), 0019 (rendering and the view transform), 0020 (focus and keyboard ownership). New module names (`view/`, `input/`, `tools/`, `chrome/`, `renderers/`, `app/keyboard/`) are the spec's; `view/` means `canvas/runtime/view/`, and so on for `input/`, `tools/`, `chrome/`.
